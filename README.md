# S-DES 加解密系统 (Python 实现)
本项目是针对S-DES算法的开发实现，采用 Python 编写，包含完整的底层算法、Tkinter 交互界面以及多线程暴力破解与安全性分析模块。
## 功能特性
- **第1关 - 基本测试**：支持 8-bit 数据的 S-DES 加密与解密，包含标准化 GUI 界面。
- **第2关 - 交叉测试**：严格遵循 S-DES 算法标准流程与置换单元，确保与异构平台结果一致。
- **第3关 - 扩展功能**：支持全 ASCII 编码字符串的输入，按 Byte 分组加密并输出二进制密文。
- **第4关 - 暴力破解**：利用 `concurrent.futures` 实现多线程暴力破解，并记录破解时间戳。
- **第5关 - 封闭测试**：包含自动化分析脚本，验证了单对明密文的多密钥现象以及同一明文下的密文碰撞现象。
## 目录结构
- `core/`：S-DES 核心算法模块 (`sdes.py`) 与测试破解脚本 (`cracker.py`)。
- `gui/`：基于 Tkinter 的图形界面模块。
- `docs/`：用户指南/开发手册，以及各关卡的测试结果文档与视频。
- `main.py`：项目 GUI 启动入口。
