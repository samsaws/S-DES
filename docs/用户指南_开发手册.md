# S-DES 系统：用户指南与开发手册
## 一、 用户指南
本系统提供直观的图形用户界面，操作步骤如下：
1. **选择模式**：启动程序后，在顶部单选框选择“8-bit 二进制模式”或“ASCII 字符串模式”。
2. **输入密钥**：在密钥框中输入确切的 10-bit 二进制密钥（如 `1010000010`）。程序内置了格式校验防呆机制。
3. **输入数据**：在数据框中输入明文或密文。
   - 若为 8-bit 模式，需输入 8 位由 0 和 1 组成的序列。
   - 若为 ASCII 模式，可直接输入英文短句。
4. **执行加解密**：点击蓝色的“S-DES 加密”或绿色的“S-DES 解密”按钮，结果将自动打印在底部的输出框中。
## 二、 开发手册
本项目采用**函数式编程**思想，核心算法与界面解耦。核心接口均封装于 `core/sdes.py` 中，方便第三方调用：
### 核心接口 API
- `generate_keys(key_10bit: str) -> tuple`
  - **功能**：密钥扩展单元。输入 10 位密钥，执行 P10、循环左移和 P8 置换，返回 `(K1, K2)`。
- `f_function(right_half: str, subkey: str) -> str`
  - **功能**：轮函数 F。包含 EPBox 扩展、异或、S-Box 查找与 SPBox 置换。
- `encrypt_8bit(plaintext: str, key: str) -> str`
  - **功能**：基础 8-bit 数据加密。返回 8 位二进制密文。
- `decrypt_8bit(ciphertext: str, key: str) -> str`
  - **功能**：基础 8-bit 数据解密。
- `encrypt_ascii(ascii_str: str, key: str) -> str`
  - **功能**：扩展功能。将字符串转为二进制并按 8-bit 分组调用基础加密，返回完整二进制密文串。
- `brute_force_crack(plaintext, ciphertext, num_threads=4)`
  - **位置**：`core/cracker.py`
  - **功能**：多线程暴力破解，利用线程池将 1024 个密钥空间分块遍历，返回匹配的密钥列表及破解耗时。
